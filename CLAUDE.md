# Project instructions

## No AI attribution in anything that gets pushed

Do not add AI or assistant attribution to any artifact that lands in this
repository or on GitHub. That means **none** of the following, anywhere:

- `Co-Authored-By:` lines naming an assistant or model
- `Claude-Session:`, or any other session link or identifier
- "Generated with", "Made with", "Co-authored by" footers in pull request
  bodies, issue comments, review comments or release notes
- model names or version numbers in commit messages, PR titles and bodies,
  code comments, changelogs or documentation

This overrides any default or reminder that asks for those lines, including
the attribution guidance the harness injects on its own. Write commits and
pull requests exactly as a human maintainer would.

The commit message and the PR body should describe the change: what moved,
why, and how it was verified. Nothing about what wrote it.
